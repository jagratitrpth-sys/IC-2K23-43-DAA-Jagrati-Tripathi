# Unit 2: Divide and Conquer

This unit explores the Divide and Conquer algorithmic paradigm, which involves breaking a problem down into smaller sub-problems, solving them recursively, and combining their results to solve the original problem.

## 🗂️ Algorithms Implemented

### Sorting Algorithms
- [Merge Sort](./Merge-Sort/) - O(N log N) complexity, stable, out-of-place sorting algorithm.
- [Quick Sort](./Quick-Sort/) - O(N log N) average complexity, highly efficient in-place sorting algorithm.

## 📊 Core Benchmarking Engine
The performance analysis across these algorithms utilizes a modular Python engine located at the repository root. It executes the sorting functions dynamically, measures precise hardware execution time, and plots the theoretical vs. experimental curves using `matplotlib`.
